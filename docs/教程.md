# 使用教程

本软件把一次 mEPSC / mIPSC 分析拆成五个页面，按顺序走一遍即可。每个分析都附带“如何读图”的说明，
这些说明在软件的结果文字里也会自动给出。

## 0. 记录前的建议

- 记录 ≥ 3–5 分钟的平稳段，串联电阻变化 < 20%。频率低的细胞（< 0.5 Hz）需要更长的记录才能做聚类和时间依赖分析。
- mini 条件：TTX（0.5–1 µM）阻断动作电位；mEPSC 常加 PTX/BIC，mIPSC 常加 CNQX/NBQX + APV。
- 采样 ≥ 10 kHz，低通 2–3 kHz。软件内可再做数字低通。
- 同一只动物的细胞记下动物编号，统计时会用到。

## 1. 记录与检测

**项目工作流（v0.1.3 起）**：在欢迎页新建项目，指定父目录和新文件夹名称；已有项目直接选择其文件夹。原始文件保存在 `raw/`；Ctrl+S 保存参数、分组、检测结果、审核标记和簇标签，正常关闭或切换项目也会保存。每次去卷积、聚类、统计运行的结果和参数独立写入 `results/`，清除当前结果不删除历史报告。转移项目应复制整个目录，而非只拷贝 HDF5 文件。

显示空间不足时，在「视图」调字号（Ctrl+= / Ctrl+-，Ctrl+0 恢复），拖动参数区右边的分隔线，必要时滚动参数面板。

**调整参数重算（v0.1.2 起）**：各页均可清除结果。检测页可选「清除当前细胞检测」（保留预处理）、「清除当前细胞预处理及检测」或「清除全部细胞检测」。清除检测也会移除关联事件、审核、簇标签和质控指标；不改记录、动物、组别、界面参数和已导出的文件。任务运行时请等它结束再清除。

审核页的「清除审核标记」恢复所有被排除的事件，并移除该细胞旧的簇标签和检测质控；去卷积页只清除预览，不撤回已采用的检测结果。聚类页按「范围」清除标签；分析与统计页清除当前显示的图文，若当前显示的是检测质控，也移除其对应细胞的质控指标。清除后调整参数，再点该页的运行按钮。

1. 「文件 → 打开记录」选择 `.abf`。多通道文件会让你选通道；episodic 记录会把所有 sweep 首尾拼接。
2. 在左侧列表双击“组别”“动物”两列填写。
3. 在左侧细胞列表中，用对应记录的「事件类型」下拉菜单选择预设。所选记录的方向、窗口和动力学参数自动更新；中间栏可继续微调。左右拖动列表右边的分隔条可调整宽度。
   - **mEPSC / sEPSC**：向下（内向）事件，窗口 30 ms。
   - **mIPSC / sIPSC（高氯内液）**：–70 mV 下 IPSC 也是内向，窗口 80 ms（衰减更慢）。
   - **mIPSC / sIPSC（低氯内液）**：0 mV 附近记录，事件向上。
4. 检测器：
   - **miniML**（推荐）：深度学习模型，阈值 0.5 是论文默认值。事件窗口应覆盖一个完整事件（约为衰减 τ 的 8–12 倍），
     miniML 会把这个窗口重采样到模型训练时的长度，因此同一个模型可用于动力学不同的事件。
     可在下拉框里选择 miniML 自带的迁移学习模型，或填入自己训练模型的完整路径。
   - **去卷积**：不依赖 TensorFlow，速度快，对重叠事件敏感；需要设置模板 τ。
5. 检测页默认低通 1000 Hz、工频陷波 50 Hz。先在细胞列表用 Ctrl/Shift 多选（macOS 可用 ⌘），调参后点「应用当前参数到选中记录」，再点「按各自参数检测选中记录」或「按各自参数检测全部细胞」。要统一整批参数时先在列表中全选。变更已处理记录的参数会先确认，再清除相关的旧结果；未选记录不受影响。

## 2. 事件审核

左侧表格逐个列出事件，选中后右上显示原位波形。按 Delete（或按钮）排除误检，再按一次恢复。
排除的事件不参与任何统计，但会保留在表格中（灰色），便于复查。

## 3. 去卷积平滑

去卷积把每个缓慢衰减的突触电流压缩成一个尖峰（Pernía-Andrade et al., 2012），因此：

- 叠在前一事件衰减相上的事件可以被分开；
- 可以画出“事件率随时间变化”的曲线，看出 burst 和慢速率漂移。

步骤：先「用本细胞平均事件拟合模板」，再「运行去卷积」。上图红线是“稀疏事件 × 模板”的重建：
贴合原始记录说明模板合适；系统性偏离提示事件动力学不均一（→ 动力学聚类）。
平滑宽度越大噪声越小、时间分辨率越低，一般取上升时间量级。

## 4. 动力学聚类

问的问题是：**这个细胞收到的事件是一类，还是几类动力学不同的事件混在一起？**

- **表征**：“波形形状”先把每个事件峰值归一化再做 PCA，只看形状、与幅度无关，推荐；“标量特征”用上升时间、衰减 τ 等。
- **方法**：GMM（默认，可用 BIC 自动选簇数）、K-means、HDBSCAN（可识别噪声点）。
- **先看证据**：结果第一行告诉你 ΔBIC（k=1 与最优 k>1 之差，>10 为强证据）和轮廓系数（>0.25 较可分）。
  证据弱时，分出来的簇可能只是把连续分布切开了，不要过度解读。
- **范围**选“全部细胞合并”后，所有细胞共用一套簇定义，再到「分析与统计 → 各簇组成的组间比较」看处理是否选择性改变了某一类事件。

常见解读：上升慢、衰减慢、幅度小 → 远端树突输入；上升相近但衰减不同 → 受体亚基/类型不同（如含 NMDA 成分的 EPSC；α1 与 α2/3/5 型 GABA_A 受体），
或不同类型中间神经元（PV 胞体周围快 IPSC vs SST 树突慢 IPSC）。

## 5. 分析与统计

| 分析 | 回答什么问题 | 怎么读 |
| --- | --- | --- |
| 细胞总览 | 这个细胞的基本参数与记录是否平稳 | 频率、幅度随时间漂移 >20–30% 时应截取平稳段 |
| 检测质控 | 检测能检出多小的事件？有多少假阳性？ | 把模板事件注入记录再检测，得到 50% 检出幅度（检测下限）；翻转记录后检出的事件数≈假阳性数。若大量事件贴近检测下限，组间“频率”差异可能只是幅度变化把事件推过了阈值 |
| 上升时间–幅度相关 | 幅度差异是否来自树突滤波 | 显著负相关（且上升–衰减正相关）提示电紧张衰减；比较幅度时可只取快上升事件 |
| 事件时间依赖性 | 一个事件之后是否更容易出现另一个事件 | 自相关在短延迟处高于替代数据带、Hawkes 分支比 >0 且显著 → 簇状释放；CV2 对慢漂移不敏感，可与 CV 对照 |
| PS-NSFA | 幅度变化来自受体数目还是单通道电导 | 给出单通道电流 i、电导 γ 和开放通道数 N；γ 不变而幅度变 → 受体数目改变。前提是动力学均一，建议在单个簇内做 |
| 量子多峰分析 | 幅度分布是否呈量子化多峰 | 峰位接近整数倍才支持；若单个对数正态分布更优，多峰多半是拟合偏态的产物 |
| E/I 联合分析 | 兴奋/抑制平衡 | 电荷比最接近“总驱动”；只有同一段记录同时检测 E 与 I 时才计算互相关 |
| 累积概率分布 | 幅度和 IEI（频率）的整体分布是否移动 | 默认按细胞平均：先求每个细胞的累积分布再平均（± SEM），每个细胞权重相同；IEI 右移 = 频率降低。检验用每个细胞的中位数 |
| 组间比较 | 两组/多组是否不同 | 每个点是一个细胞；有 ≥6 只动物且同一动物多个细胞时自动用混合模型；另给出层级 bootstrap 和事件水平混合模型。**不要把所有事件合并后做 KS 检验**（伪重复会严重夸大显著性） |
| 突触缩放 | 处理是否按同一比例放大/缩小所有突触 | 秩序图斜率与迭代缩放因子；除以因子后分布重合 → 均一乘性缩放；比例图不平坦 → 非均一缩放 |
| 各簇组成比较 | 处理是否只影响某一类输入 | 先做“全部细胞合并”聚类 |

每个结果都可以「导出图」（PDF/SVG 字体可编辑，可直接在 Illustrator 里改）和「复制结果文字」。

## 6. 导出

「文件 → 导出结果表」生成：

- `*_events.csv`：每个事件一行（细胞、组别、动物、时间、各项特征、所属簇）；
- `*_cells.csv`：每个细胞一行（频率、各特征的均值/中位数/CV、噪声、检测下限、假阳性率、各簇比例与频率）。

这两张表可以直接导入 GraphPad Prism、R 或 Python 做进一步分析。

# v0.2.6：补录、续跑与复核

- **人工补录突触事件**：先检测当前记录，在「记录与检测」放大一个疑似漏检峰。点击「框选潜在事件」，拖动时间带，让左边界靠近上升起点，右边界越过该峰，但不要包含其他峰。点击「测量并补录选区」核对指标后确认。框用于定位峰；基线取自框前，衰减拟合和积分可延伸到框外。噪声或重叠事件也可能产生拟合值，请结合原波形审核。NaN 代表不可测，不是零。手动事件不赋予模型得分；可在事件审核中排除，重新检测会替换整个事件表。
- **续跑**：批量检测前自动保存项目。重开项目后查看「检测状态」列，用「续跑未完成、失败或待重算记录」只处理缺失或不再匹配的记录；查看失败原因后再重试。检查点只用于检测，未完成的单条记录从头再算。保留项目整个目录（包括隐藏的 .checkpoints）。
- **报告追踪**：文件菜单的「检查归档报告是否需要重算」比较当前项目与生成报告时的参数、数据标识和审核状态。旧报告不追溯推断；重新计算会归档新结果，不会覆盖旧图。
- **导入预览**：核对文件名、目录提示、分组及事件类型；可编辑分组，并选中多行应用同一预设。关键词冲突是提醒，不是从波形测出的极性。
- **内在兴奋性复核**：分析完成后点击 F–I 图上的点或选择 sweep，下方显示原始电压、电流指令、刺激时间带及检测到的 AP 峰。
# 多级分组和矢量导出

递归选择 WT 文件夹导入 WT/动物1/CA1 下的记录时，列表的目录 1、2、3 分别为 WT、动物1、CA1；层级不足留空。修改表中目录标签不会更改磁盘目录。「分析与统计 → 统计分组依据」可选目录层级、手动组别、动物、备注或事件类型；空标签不纳入组间比较。右键预览图选择导出 SVG，可在矢量编辑器中修改。
# v0.2.8：审核保存与组间统计

检测或批处理结束（包括正常取消）后，所有细胞的事件表、波形、参数及审核标记自动写入项目根目录的 project.pca.h5。手动补录、排除、恢复后再次写入。批处理中仍保留临时检查点；请保留整个项目目录以便重开原始记录。事件审核页的「导出全项目审核后统计（CSV）」以细胞为行，只用未排除的事件计算频率与动力学，并列出原始条数、排除数及保留的手动条数。

「分析与统计」先选 EPSC 或 IPSC，再选包含 WT、KO 或其他条件的组别列或目录层级；不会将两类电流合并。请给同一动物使用稳定、全项目唯一的动物编号。不同动物间的指标比较按动物汇总，推荐秩检验；同一批动物在各条件下完整重复测量时使用配对检验。缺失编号或部分配对仅作描述。CDF 保留原有细胞等权平均画法，置换检验采用动物作为单位。
